# Tuần 10 – Oẳn tù tì

Chọn Búa, Bao hoặc Kéo (bấm chuột hoặc phím 1, 2, 3). Hai bàn tay lắc theo nhịp đếm ngược 3-2-1 rồi ra kết quả. Tỉ số vẫn còn sau khi tải lại trang.

| Kiến thức | Ở đâu |
|---|---|
| useEffect + cleanup | Đếm ngược trong `App.jsx`, `clearTimeout` khi effect chạy lại |
| Custom hook | `hooks/useLocalStorage.js` (lưu tỉ số), `hooks/useKeyPress.js` (phím tắt) |
| addEventListener + cleanup | trong `useKeyPress` |

```bash
npm install
npm run dev
```
